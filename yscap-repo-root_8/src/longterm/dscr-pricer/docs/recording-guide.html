One more recording — here's exactly what to click

A single session in Lender Price captures everything still missing. The trick is one rule that explains why the last recording didn't catch the checkboxes.

⚠️

The one rule: after every change, make it re-price

A checkbox or dropdown by itself does not fire a search — so it never gets recorded. That's exactly why the last recording shows escrow still on even though you unchecked it. After each change below, make sure the prices refresh (click Search / Re-price, or nudge the loan amount by $1 and back). If the results didn't visibly reload, it wasn't captured.

1 Set up the recording

  1. Open the pricer, then open DevTools — press F12 (or right-click → Inspect), and click the Network tab.
    Same as before.
  2. Check "Preserve log" at the top of the Network tab.
    So it keeps everything across the whole session.
  3. Do a baseline search first — a plain single-family purchase, $500,000 value, $375,000 loan, 760 FICO, DSCR 1.25, 5-year prepay. Let the prices load.
    This is the reference every later change is compared against.

3 Save it

  1. Right-click anywhere in the Network list → "Save all as HAR with content", and name it something like dscr-tokens.har.
  2. Send me that one file. One HAR with the whole sequence is all I need — I read the differences between each search to pull out every token.
Remember

The HAR contains your login. After you export it, treat it as a secret and it's still worth rotating that Lender Price password.
